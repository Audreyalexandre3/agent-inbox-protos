# Agent Inbox prototypes

Two throwaway prototypes of the agentic inbox (fake data, brand "Halden & Co"), built to compare two ways of organizing the same engine:

- `a.html` Dashboard: one home page, suggestions grouped by message type, bulk actions, live activity rail.
- `b.html` By agent: one space per agent (to review, activity, guidelines), "Needs you" as its own entry.

Shared engine in `core.js` (state, actions, live feed, detail drawer, log) and `data.js` (fake items). No build step.
