Agent Inbox : deux façons d'organiser le même socle

Les deux versions partagent le même moteur : on voit en direct ce que font les agents, on agit sur l'essentiel, on corrige et l'agent apprend. Seule l'organisation change.

A

Dashboard

  • Une page d'accueil : ce qui attend, regroupé par type de message
  • « Needs you » épinglé en haut
  • Bulk sur les likes et le spam, replies relus une par une ou par sélection
  • Activité en direct à droite, agents en réglage secondaire
Ouvrir A → B

Par agent

  • On entre dans l'espace d'un agent (Lead par défaut)
  • Chaque agent : à valider, activité, guidelines
  • « Needs you » comme entrée à part dans la navigation
  • Réglages et feedback dans le contexte de l'agent
Ouvrir B →

Commun aux deux

  • 4 agents : Lead, Support, Engagement, Modération
  • Mode suggestion : approuver, modifier, refuser
  • Actions natives : reply (+ DM produit), like, hide
  • Escalades et knowledge gaps jamais traités seuls
  • Nouveaux messages en direct toutes les ~10 s
  • Refus avec raison ou « mauvais agent » → apprentissage
  • Après 8 validations sans refus : proposition de passer en auto
  • Tout est annulable depuis le log
